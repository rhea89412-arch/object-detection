🎥 Live Object Detection & Tracing

A real-time object detection and tracking web app built with Streamlit, YOLOv8, and WebRTC.
This application uses your webcam to detect and track objects live in the browser with smooth streaming performance.

🚀 Features
📷 Real-time webcam streaming
🧠 YOLOv8 object detection
🔍 Object tracking with persistent IDs
⚡ Fast and lightweight (yolov8n.pt)
🌐 Browser-based interface using Streamlit
🎥 Smooth video rendering with WebRTC
🛠️ Technologies Used
Python
Streamlit
streamlit-webrtc
Ultralytics YOLOv8
OpenCV
PyAV
